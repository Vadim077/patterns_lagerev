| Наименование сущности | Описание | Связи с другими сущностями |
| --- | --- | --- |
| **Базовая абстракция (name_id)** | Абстрактный класс верхнего уровня. Содержит защищённый `id` (геттер) и `name` (геттер и сеттер). | Родительский класс для: *Единица измерения, Ингредиент, Сотрудник, Контрагент, Группа, Ресторан (наследование)*. |
| **Единица измерения (Unit)** | Простая сущность. Мера веса, объёма или количества (г, мл, кг, шт). | *name_id (наследование)*, Ингредиент (ассоциация), Группа (агрегация). |
| **Деньги (Money)** | Простая сущность (Value Object). Числовая сумма и валюта для финансовых расчётов. | Блюдо (ассоциация / поле стоимости), Контракт (ассоциация), Заказ (ассоциация / итоговый чек). |
| **Ингредиент (Ingredient)** | Простая сущность. Сырьевой продукт с привязкой к базовой мере. | *name_id (наследование)*, Единица измерения (ассоциация), Технологическая карта (агрегация), Блюдо (агрегация), Склад (ассоциация). |
| **Адрес / Адрес доставки (Address)** | Простая сущность. Географические данные (улица, дом, координаты). | Ресторан (композиция), Заказ (ассоциация). |
| **Сотрудник (Employee)** | Простая сущность. Работник заведения (ФИО, должность). | *name_id (наследование)*, Ресторан (агрегация), График работы (агрегация), Контракт (ассоциация). |
| **Контрагент (Contractor)** | Простая сущность. Поставщик сырья или сторонний контрагент. | *name_id (наследование)*, Контракт (агрегация), Группа (агрегация). |
| **Группа (Group)** | Простая сущность. Иерархическая категория (может содержать подгруппы). | *name_id (наследование)*, Группа (ассоциация / ссылка на родителя), Единица измерения (агрегация), Контрагент (агрегация). |
| **Блюдо / Номенклатура блюд (Dish)** | Комплексная сущность. Позиция меню с ценой, весом и составом. | Технологическая карта (композиция), Ингредиент (агрегация), Деньги (ассоциация), Ресторан (агрегация), Заказ (агрегация). |
| **Технологическая карта (Recipe)** | Комплексная сущность. Производственная спецификация: раскладка сырья, граммовки и алгоритм готовки. | Блюдо (композиция / часть блюда), Ингредиент (агрегация), Единица измерения (ассоциация). |
| **Склад (Storage)** | Комплексная сущность. Учётный узел хранения остатков сырья и полуфабрикатов. | Ресторан (композиция), Ингредиент (ассоциация / остатки), Заказ (ассоциация / списание). |
| **Ресторан / Компания (Restaurant)** | Комплексная сущность. Филиал сети со своими ресурсами и точкой продаж. | *name_id (наследование)*, Адрес (композиция), Склад (композиция), Сотрудник (агрегация), Блюдо (агрегация), Заказ (ассоциация). |
| **Контракт (Contract)** | Комплексная сущность. Договор поставки или оказания услуг. | Контрагент (агрегация), Сотрудник (ассоциация / ответственный), Деньги (ассоциация). |
| **График работы (WorkSchedule)** | Комплексная сущность. Расписание и распределение рабочих смен по времени. | Ресторан (композиция), Сотрудник (агрегация). |
| **Заказ (Order)** | Комплексная сущность. Сквозной бизнес-процесс продажи и доставки клиенту. | Ресторан (ассоциация), Блюдо (агрегация), Адрес доставки (ассоциация), Склад (ассоциация), Деньги (ассоциация). |
